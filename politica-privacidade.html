Política de Privacidade

Última atualização: agosto de 2026

Esta Política de Privacidade explica como o Prato Certo recolhe, usa e protege os teus dados pessoais quando visitas este site ou usas a área de membros.

1. Que dados recolhemos

Ao comprares o produto, recolhemos o teu nome, email e telefone através do processador de pagamento (Hotmart). Ao usares a área de membros, guardamos o teu progresso nas receitas e preferências dentro da aplicação.

2. Como usamos os teus dados

  • Para criar e dar acesso à tua conta na área de membros
  • Para comunicar contigo sobre a tua compra ou suporte
  • Para melhorar o produto com base no uso agregado e anónimo

3. Partilha de dados

Não vendemos os teus dados a terceiros. Usamos fornecedores de confiança para processar pagamento (Hotmart) e alojar a aplicação (Supabase, Cloudflare), que têm as suas próprias políticas de privacidade e segurança.

4. Os teus direitos

Ao abrigo do RGPD, tens direito a aceder, corrigir ou eliminar os teus dados a qualquer momento. Contacta-nos pelo WhatsApp para exercer estes direitos.

5. Segurança

Usamos encriptação e boas práticas de segurança para proteger os teus dados, mas nenhum sistema é 100% infalível.

6. Contacto

Dúvidas sobre esta política? Fala connosco pelo WhatsApp.
